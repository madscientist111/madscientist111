I'm Devanshu Bhatt (shoo), a full-stack and product engineer in Ahmedabad, India. I mostly build AI agents and their infrastructure in TypeScript on Cloudflare Workers and Durable Objects.

## What I'm building

- [Benny](https://github.com/madscientist111/benny): a coding agent that lives in GitHub issues. Mention it and it researches, opens a PR and fixes the review comments. Each thread runs in its own Durable Object, a small decision model picks between replying, reacting and staying quiet, it only writes when the requester has write access, and it never merges its own PRs. A personal experiment, shared as a reference.
- [pi-durable-chat](https://github.com/madscientist111/pi-durable-chat): a multi-conversation agent chat app on Workers, with one Durable Object per user, runs that survive disconnects, email-code sign-in, per-user model budgets, and GitHub writes that need approval in the UI.
- [Cloudflare-Builds-VSX](https://github.com/madscientist111/Cloudflare-Builds-VSX): a VS Code extension to watch Cloudflare Workers Builds for the open repo (work in progress).
- [pdf-genie](https://github.com/madscientist111/pdf-genie): an AWS Lambda container that converts documents to PDF with LibreOffice.
- [screenshotter](https://github.com/madscientist111/screenshotter): a small Puppeteer screenshot API in Docker.

I'm also building [Supapost](https://usesupapost.com) and [Skrapbook](https://skrapbook.app), and I do project work with [VoxIntel AI](https://voxintelai.com). Most of my work is in private repos, so the contribution graph says more than the repo list.
